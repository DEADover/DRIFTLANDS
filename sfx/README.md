# `sfx/` — your own engine, optional

Drop audio files in this folder and the game uses them instead of the
synthesised engine. Leave it empty and nothing changes: the synth in
`src/audio/audio.js` is the shipping engine and stands on its own. No code
change either way.

Same mechanism as `music/`: Vite enumerates the folder at build time, so
dropping a file in and letting the dev server reload is the entire procedure.

## Slots

Name the file after the slot. Any subset — you do not need all of them.

| file | what it should contain |
|---|---|
| `engine_idle` | closed throttle, low revs, steady |
| `engine_onload` | wide open throttle, steady, **one gear, no shifts** |
| `engine_overrun` | trailing throttle at speed, crackle and pops included |
| `shift` | one-shot upshift |
| `shift_down` | one-shot downshift (falls back to `shift`) |

Providing `engine_onload` on its own is enough to take the engine off the
synth; missing states fall back to the nearest slot present.

Formats: `wav` `mp3` `ogg` `oga` `m4a` `aac` `flac` `webm` `opus`.

## The two rules that matter

**Engine loops must be steady-state and seamless.** One recording covers the
whole rev range, played back faster or slower to follow the revs — which is how
every driving game does it. Anything inside the loop that is not a constant rpm
(a gear change, a rev drop, a bump) will be audibly stretched.

**Say what rpm you recorded at**, in the filename, or the pitch will be wrong:

```
engine_onload@4200rpm.wav
```

Without the suffix 3000 rpm is assumed. Playback rate is crank rpm divided by
that number, and the game reads its rev range as 950 rpm at idle to 7000 at the
redline.

## What the samples do and do not replace

They replace the sound. They do not replace the behaviour: the load and overrun
inference, the crossfade between idle, on-load and overrun, the torque cut on a
gear change and the pitch trajectory across it all still run. A `shift` one-shot
lands inside a real gap in the engine rather than on top of it.

They also bypass the synthesised exhaust resonances, deliberately — a recording
already has a pipe in it and does not want a second one.

## If a file will not play

It is reported once in the console and skipped, and the engine stays on the
synth. There is no way for a bad file in here to leave the game silent.
